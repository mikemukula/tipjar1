# Tip Jar — Frontend

React + Vite frontend for the [G$ Tip Jar](../README.md) creator tipping platform.

See the [root README](../README.md) for project overview and full setup instructions.

## Quick Start

```bash
npm install
npm run dev
```

Start the [backend API](../backend/) on `http://localhost:5001` before using the dashboard or tipping flow.

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start development server |
| `npm run build`   | Production build         |
| `npm run preview` | Preview production build |
| `npm run lint`    | Run ESLint               |
